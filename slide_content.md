## Slide 6: Warum TypeScript/React statt WordPress? – Sicherheit

**Kernaussage:** WordPress ist das meistangegriffene CMS der Welt – 11.334 neue Sicherheitslücken allein in 2025.

**Fakten:**
- 11.334 neue Vulnerabilities im WordPress-Ökosystem 2025 (+42% gegenüber Vorjahr)
- 92% aller erfolgreichen Angriffe über Plugin-Schwachstellen
- 13.000 WordPress-Seiten werden täglich gehackt
- Median Time-to-Exploit: nur 5 Stunden nach Bekanntwerden einer Lücke
- Unsere Lösung: Zero-Plugin-Architektur – kein WordPress, keine Plugins, keine Angriffsfläche

**Vergleich:**
| | WordPress | GBG (React/TypeScript) |
|---|---|---|
| Angriffsfläche | Tausende Plugins | Keine externen Plugins |
| Updates nötig | Wöchentlich (Core + Plugins) | Nur bei Feature-Änderungen |
| Bekannte Lücken 2025 | 11.334 | 0 (Custom Code) |
| Datenschutz-Risiko | Hoch (Plugin-Datenabfluss) | Minimal (volle Kontrolle) |

## Slide 7: Warum TypeScript/React statt WordPress? – Performance

**Kernaussage:** Nur 40% der WordPress-Mobile-Sites bestehen Googles Core Web Vitals – unsere Lösung erreicht nahezu 100%.

**Fakten:**
- WordPress: Nur 40% bestehen Core Web Vitals auf Mobile (HTTP Archive 2024)
- React SPA: Keine Server-Roundtrips bei Navigation → sofortige Seitenübergänge
- Code-Splitting: Nur der Code wird geladen, der aktuell gebraucht wird
- TypeScript: Compile-Time-Fehlerprüfung verhindert Runtime-Crashes

**Performance-Vergleich:**
| Metrik | WordPress (typisch) | GBG (React) |
|---|---|---|
| First Contentful Paint | 2.5-4.0s | < 1.0s |
| Largest Contentful Paint | 3.5-6.0s | < 1.5s |
| Time to Interactive | 4.0-8.0s | < 2.0s |
| Cumulative Layout Shift | 0.15-0.30 | < 0.05 |
| Seitennavigation | Vollständiger Reload | Instant (SPA) |

## Slide 8: Warum TypeScript/React statt WordPress? – Langfristige Vorteile

**Kernaussage:** Die Investition in eine Custom-Lösung zahlt sich durch geringere Wartungskosten, bessere SEO und höhere Conversion-Rates aus.

**Punkte:**
- **SEO-Vorteil:** Google bevorzugt schnelle Seiten – Core Web Vitals sind seit 2021 Ranking-Faktor
- **Wartungskosten:** WordPress erfordert ständige Updates (Core, Themes, Plugins) – Custom-Code nur bei gewünschten Änderungen
- **Skalierbarkeit:** Neue Features (Kundenportal, Rechner) nahtlos integrierbar ohne Plugin-Konflikte
- **Zukunftssicherheit:** WordPress-Marktanteil sinkt erstmals (unter 43% in 2026) – React/TypeScript ist der Industriestandard
- **Datenschutz (DSGVO):** Volle Kontrolle über Datenflüsse – kein Plugin telefoniert nach Hause
